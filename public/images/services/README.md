# E Zennith — Media & Service Images Directory Guide

Welcome! This folder contains all the custom static images used throughout the **E Zennith** website.

---

## 🚀 How to Replace Any Image (No Code Required!)
When your graphics designer delivers custom graphics or whenever you want to swap any picture:
1. **Name your new image file** with the exact same name as listed in the table below (e.g. `amazon-ppc-advertising.jpg` or `amazon-advertising.jpg`).
2. **Copy and replace** the file inside the corresponding subfolder under `public/images/services/`.
3. **Refresh the website** — the new image will automatically appear instantly across all relevant service cards and subpages!

---

## 📐 Recommended Image Specifications
- **Format:** `.jpg` or `.webp`
- **Aspect Ratio:** `16:9` (e.g., `1200 x 675 px` or `800 x 450 px`)
- **File Size:** Under `250 KB` per image for sub-second page load speeds.
